# Kubebuilder Operator Project Structure (Phase 1 Explanation)

Welcome to Go and Kubernetes Operator development! Because Kubebuilder scaffolds a complete, production-ready project layout, there are suddenly many files. Here is a simple, short guide to what each file does.

---

## Core Operator Directories & Files

### 1. The Entry Point: `cmd/`
*   **[cmd/main.go](file:///home/ayoub/Documents/Preview-Operator/cmd/main.go)**
    *   **What it is**: The main entry point of the application.
    *   **What it does**: Starts the "Manager" process. The Manager coordinates your controller(s), sets up logging, starts metric endpoints, and listens for cluster events.

### 2. The Schema / API Definition: `api/`
*   **[api/v1alpha1/previewenvironment_types.go](file:///home/ayoub/Documents/Preview-Operator/api/v1alpha1/previewenvironment_types.go)**
    *   **What it is**: The definition of your Custom Resource (CRD).
    *   **What it does**: Holds the Go structs representing the YAML schema. Any field you add here translates directly to a field in your Kubernetes YAML file.
        *   `PreviewEnvironmentSpec`: Fields defining the **desired state** (what you want).
        *   `PreviewEnvironmentStatus`: Fields defining the **observed state** (what the operator measures).
*   **[api/v1alpha1/groupversion_info.go](file:///home/ayoub/Documents/Preview-Operator/api/v1alpha1/groupversion_info.go)**
    *   **What it is**: Metadata configuration file.
    *   **What it does**: Defines the API Group (`preview.preview.io`) and Version (`v1alpha1`) and registers these custom Go types with the Kubernetes API machinery.

### 3. The Reconciler / Logic: `internal/controller/`
*   **[internal/controller/previewenvironment_controller.go](file:///home/ayoub/Documents/Preview-Operator/internal/controller/previewenvironment_controller.go)**
    *   **What it is**: The brain of your operator.
    *   **What it does**: Contains the `Reconcile` function. Every time a `PreviewEnvironment` is created, updated, or deleted, Kubernetes alerts this function. The function's job is to read the desired state (Spec) and make changes to the cluster (like creating namespaces or applications) to match it.
*   **[internal/controller/previewenvironment_controller_test.go](file:///home/ayoub/Documents/Preview-Operator/internal/controller/previewenvironment_controller_test.go)**
    *   **What it is**: Unit test file.
    *   **What it does**: Tests the reconciliation logic locally using simulated Kubernetes api requests.
*   **[internal/controller/suite_test.go](file:///home/ayoub/Documents/Preview-Operator/internal/controller/suite_test.go)**
    *   **What it is**: Test suite bootstrapping file.
    *   **What it does**: Starts `envtest` (a local, lightweight control plane with an API server and etcd) so you can run unit tests without needing a real cluster.

## Configuration & YAMLs: `config/`

Kubebuilder uses **Kustomize** (a template-free YAML customization tool) to manage manifests:

*   **`config/crd/`**: Automatically generated Kubernetes CustomResourceDefinition (CRD) schemas that tell your Kubernetes cluster about the new `PreviewEnvironment` resource.
*   **`config/rbac/`**: Auto-generated permissions (Role/ClusterRole) specifying what access the operator has (e.g. read Pods, write Services).
*   **`config/manager/`**: Manifests to deploy the operator controller binary as a pod container in the cluster.
*   **`config/samples/`**: Sample YAML instances of your Custom Resource (useful for running `kubectl apply -f`).

## Project Metadata & Build Tools

*   **[Makefile](file:///home/ayoub/Documents/Preview-Operator/Makefile)**
    *   **What it does**: Contains common build targets:
        *   `make generate`: Re-runs deepcopy code generators for your custom Go types.
        *   `make manifests`: Converts comments in Go files starting with `// +kubebuilder:...` into YAML manifests (like CRD schemas and RBAC rules).
        *   `make build`: Compiles the Go binary.
        *   `make install`: Registers the CRD manifests into your active Kubernetes cluster.
        *   `make test`: Runs unit tests.
*   **[go.mod](file:///home/ayoub/Documents/Preview-Operator/go.mod) / [go.sum](file:///home/ayoub/Documents/Preview-Operator/go.sum)**
    *   **What they are**: Go dependency management files (similar to `package.json` in Node.js).
*   **[PROJECT](file:///home/ayoub/Documents/Preview-Operator/PROJECT)**
    *   **What it is**: Auto-generated Kubebuilder tracking file.
    *   **What it does**: Tracks metadata about your API groups, versions, and CLI flags used. **Do not edit this file manually.**
